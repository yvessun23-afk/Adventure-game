# Spielstände (Backup)

Hier kannst du deine Spielstand-Dateien (`*.neonsave`) ablegen.

**Sichern:** Im Spiel auf Speichern/Laden, dann „Alle Spielstände als Datei sichern". Die Datei dann hier hochladen
(GitHub: Ordner `backup` öffnen, **Add file → Upload files**).

**Wiederherstellen:** Datei von hier herunterladen, im Spiel auf Laden, dann „Spielstände aus Datei laden".

Hinweis: Ist das Repository öffentlich, kann jeder diese Dateien sehen. Sie enthalten nur den Spielfortschritt und deine Optionen.
